# Humza Khaliq — Portfolio

Personal portfolio built on the [vCard template](https://github.com/codewithsadee/vcard-personal-portfolio) by codewithsadee. Static HTML, CSS, and JavaScript.

## Run locally

```bash
cd vcard-personal-portfolio
npx serve .
```

Then open the URL shown in your terminal (usually http://localhost:3000).

## Structure

- `index.html` — main site (About, Resume, Portfolio, Contact)
- `assets/css/style.css` — styles
- `assets/js/script.js` — tab navigation and sidebar
- `assets/images/` — photos and icons
- `assets/resume.pdf` — downloadable resume
